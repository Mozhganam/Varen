# راهنمای ساخت خودکار APK (Debug)

۱. در GitHub یک ریپازیتوری جدید بساز (مثلاً `varen-app`).
۲. فایل‌های این پوشه را در آن آپلود و commit کن.
۳. از تب "Actions" گزینه‌ی "Build Android APK (Debug)" را انتخاب کن.
۴. روی "Run workflow" بزن.
۵. پس از چند دقیقه، در پایین صفحه بخش "Artifacts" نمایان می‌شود.
۶. روی `varen-debug-apk` کلیک کن و فایل APK را دانلود کن.

✅ این نسخه فقط برای تست است و نیاز به امضا ندارد.
